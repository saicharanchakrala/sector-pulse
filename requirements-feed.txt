# vaderSentiment, so the image does not carry them - that is most of the

# fresh every time the service scales up from zero.

# Kept as its own file rather than a marker in requirements.txt because
# the app and the feed now genuinely run in different places, and one list
# describing both would grow the image every time the UI gained a chart.
